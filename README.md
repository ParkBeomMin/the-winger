# 더 윙어 2 : 라이벌 ⚽

운명의 라이벌과 함께 크는 축구선수 육성 브라우저 게임. [더 윙어](https://parkbeommin.github.io/grow-games/soccer/)의 v2 실험작이에요.

- 🎨 내 선수 꾸미기 (피부·헤어·등번호, 유니폼은 클럽 색을 따라가요)
- ⚔️ 은퇴할 때까지 함께 자라는 라이벌 (대회 결승, 리그 맞대결, 득점왕, 발롱도르)
- 🗳️ 선택형 이벤트 19종 (라이벌 관계와 은퇴식 결말이 달라져요)
- 🌍 6개 리그(K리그1·J리그·네덜란드·포르투갈·스페인·잉글랜드) 60개 클럽 960명이 매 라운드 같은 엔진으로 실제 경기를 치르는 축구 세계
  - 선수마다 능력치 6개·국적·나이·폼·부상·시즌별 커리어 기록, 매 오프시즌 성장·노쇠·은퇴·신인·AI 이적
  - 리그 18라운드(홈·원정), 챔피언스 컵·아시아 챔피언스 컵, 4시즌마다 8개국 월드컵(국적별 실제 대표팀)
  - 순위표·득점·도움·평점 순위, 경기 리포트, 선수 프로필, 축구 소식 뉴스
- 🎚️ 난이도 3단계(쉬움·보통·어려움)
- 🛡️ 60개 구단 엠블럼 (Muse 제작), 경고·퇴장·경기 중 부상·출전 정지
- 🏟️ 2D 경기 중계 + 포지션별 승부처 미니게임: ⚽ 슈팅(골문 9칸 코스+파워), 🏃 1:1 돌파(페인트), 🎯 침투 패스(오프사이드), 🛡️ 태클 타이밍(파울·경고), 🥅 페널티킥·승부차기
- ⏩ 자동 진행, ⚡ 결과만 보기, 📅 대회 일정·컨디션 경고
- 🃏 은퇴 시 공유용 선수 카드

일러스트(타이틀, 경기장, 시상식, 은퇴식, 이벤트 19종)는 Muse로 만들었어요.
